# Витрина смартфонов (только фронтенд)

Проект демонстрирует витрину смартфонов (только фронтенд)
 на Vue 3. Приложение полностью автономно: данные подгружаются из моков, оформление заказа имитируется на клиенте, а история заказов сохраняется в `localStorage`. Это позволяет безопасно добавлять проект в портфолио без развёртывания бэкенда.

## Стек
- Vue 3, Vue Router
- Vite
- Tailwind CSS

## Возможности
- каталог с фильтрами по бренду и поиском по модели
- избранное и корзина с сохранением локального состояния
- оформление заказа с генерацией номера и журналом заказов
- не требуется внешний сервер или API

## Как запустить
```bash
cd front
npm install
npm run dev
```

Сборка продакшн-версии выполняется командой `npm run build`.
